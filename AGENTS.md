# AGENTS.md — правила работы в этом репозитории

> **Читай этот файл первым делом.** Он обязателен для любого агента, который
> продолжает работу над проектом.

## Порядок чтения контекста (обязательно)

1. `AGENTS.md` (этот файл) — правила и стиль.
2. `PROJECT_CONTEXT.md` — что это за проект, стек, схема БД, роуты, решения.
3. `PLAN.md` — план по спринтам и статус задач.
4. `WORKLOG.md` — что уже сделано и проверено. **Найди последнюю запись.**

## Главный закон проекта

**Фазы выполняются подряд, без ручной проверки пользователя между ними.**
Пользователь подключается дважды и только на рубежах из `PLAN.md`:

- **Рубеж A — usable MVP:** после завершения Фазы D. Здесь всё, что требует
  критериев приёмки из ТЗ, должно работать руками.
- **Рубеж B — сдача:** после завершения Фазы F.

Внутри фаз качество обеспечивает агент сам. Его проверка на каждой фазе:
`pytest` зелёный **плюс** новые тесты на код этой фазы. Пропускать фазу без
тестов нельзя. Каждая завершённая фаза отмечается в `WORKLOG.md` с указанием,
чем именно проверено.

## Коммиты

**Один финальный коммит в самом конце**, и только по прямой просьбе
пользователя. Промежуточных коммитов не делать, если явно не попросили.
Перед коммитом: `pytest` зелёный, `git status` чист (в индексе нет
`__pycache__`, `*.db`, `.env`, `.venv`).

## Команды

Работай **только** через виртуальное окружение `.venv` (в папке проекта):

```powershell
# Активация (одна строка, без перехода в папку)
$env:PYTHONIOENCODING="utf-8"; & ".\.venv\Scripts\python.exe" ...

# Запуск сервера
& ".\.venv\Scripts\python.exe" -m uvicorn core.main:app --reload --port 8000

# Тесты
& ".\.venv\Scripts\python.exe" -m pytest -q

# Создать/пересоздать схему БД
& ".\.venv\Scripts\python.exe" -m database.init_db
```

`$env:PYTHONIOENCODING="utf-8"` обязателен: путь проекта содержит кириллицу,
без неё pip/pytest падают с `UnicodeEncodeError` (cp1251).

## Правила кода

- **Python 3.12**, типизация аннотациями на публичных функциях.
- Строгие границы слоёв. Зависимости текут только так:
  `router (HTTP) -> service -> repository -> database`.
  - `*/router.py` — только HTTP: разбор запроса, вызов сервиса, выбор шаблона.
  - `*/crud.py`, `*/service.py` — бизнес-логика, **не знает про HTTP**.
  - `database/repositories/` — **только SQL**, никакой логики и знания о HTTP.
- Комментарии в коде **не пиши**, если об этом не попросили явно. Комментарии
  в коде = запах. Пояснения живут в `PROJECT_CONTEXT.md` и docstring'ах,
  когда они действительно нужны.
- Никаких `print()` в приложении — используй `logging`.
- Никаких `except Exception: pass`. Логируй неожиданное, ре-raise или не лови.
- Именования: `snake_case` для функций/переменных, `PascalCase` для моделей,
  `UPPER_CASE` для констант. Русский текст в UI, английский в коде.
- Все тексты интерфейса проходят через `gettext`-совместимый `_(...)`? —
  **Нет.** Проект без i18n, строки на русском пишутся напрямую в шаблонах.

## Правила данных

- Миграций нет. Схема создаётся из метаданных SQLAlchemy: `python -m database.init_db`.
  После изменения моделей выполни эту команду заново (в dev БД можно удалить).
- Все связи с `ON DELETE CASCADE`, чтобы удаление опроса не оставлял мусор.
- `answers` хранят один ряд на ответ; варианты `multiple` — несколько рядов
  с `kind='multiple'`. Пустой ответ пишется как `kind='skipped'`.
- Никогда не отдавай наружу `owner_id`/`token` в JSON без явной нужды.

## Безопасность

- Сессия владельца — подписанная cookie (`itsdangerous`), `httpOnly`, `SameSite=Lax`.
- Статистика опроса закрыта: нужен `?key=<token>` из `survey_keys` **или**
  владельческая сессия. `/s/{slug}` (прохождение) — публичный.
- Сравнение токенов — константное время (`secrets.compare_digest`).
- Не логировать токены, ключи и полные ответы респондентов.

## Redis — всегда с фолбэком

Redis **опционален**. `analytics/cache.py` обязан работать, когда Redis
недоступен (in-memory словарь). Приложение не должно падать при отсутствии
Redis и не должно требовать его для работы. Проверяй оба пути.

## Перед коммитом

1. `& ".\.venv\Scripts\python.exe" -m pytest -q` — зелёное.
2. Убедись, что нет `__pycache__`, `*.db`, `.env` в индексе (см. `.gitignore`).
3. Обнови `WORKLOG.md` и, если статус поменялся, `PLAN.md`.
4. Коммит делает агент **только по прямому запросу пользователя**.

## Когда сомневаешься

Приоритет: **работающий код, который можно потрогать руками** > полнота >
элегантность. Не пиши то, что не просили. Не добавляй «на будущее».
