Сложность: ★★★★ — супер сложный

Что это: сервис, который создаёт опросы с уникальными ссылками, собирает ответы и показывает статистику.
Зачем нужен: Позволяет быстро собирать обратную связь: анкеты, тесты, голосования.
Какую задачу решает: Заменяет Google Forms для простых сценариев: создатель делает опрос, респонденты проходят по ссылке, результаты собираются автоматически.
Польза
Генерация уникальных ссылок.
Связь сущностей: опрос → вопросы → ответы.
Построение статистики.
Что должно быть в проекте
Создание опроса с вопросами и вариантами ответов.
Уникальная ссылка для прохождения каждого опроса.
Сохранение ответов в SQLite.
Более подробно о задании ↘️
🎯 Цель
Создать полноценный мини-SaaS сервис для создания опросов, сбора ответов и просмотра статистики.

Проект объединяет навыки:

проектирования базы данных;
работы пользователей;
генерации ссылок;
аналитики.
1. 🧩 Формат (Спринт)
Вы создаёте сервис для компаний, которым необходимо быстро собирать обратную связь от клиентов.

Примеры использования:

опрос удовлетворённости;
анкета после покупки;
тестирование знаний.
2. 📋 Контекст (симуляция клиента)
Компания хочет заменить простые формы в таблицах.

Сейчас:

ответы собираются вручную;
сложно анализировать результаты;
нет единой системы хранения.
Необходимо создать собственный сервис опросов.
